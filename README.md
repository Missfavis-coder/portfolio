# Ojo Adeshola — Portfolio

My personal portfolio showcasing my work, experience, education, and the technologies I use as a frontend developer.

Built with a focus on clean interfaces, subtle motion, and a simple editorial visual style.

## Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* Framer Motion
* Lucide React
* React Icons

## Features

* Selected projects and case studies
* Professional experience
* Education
* Technologies and tools
* CV download
* Responsive design
* Smooth animations and interactions
* GitHub and social links

## Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
